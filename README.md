# FM ActionLink - Kits 3D

**Português** | [English](#english)

Mostra os uniformes do Football Manager 26 em 3D, dentro do próprio jogo.

- No cartão **Sobre o Clube**, as camisas 2D viram camisas 3D, com um balanço suave.
- Um botão no título do cartão abre o boneco completo em 3D (camisa, calção, meiões e chuteiras), com abas para os uniformes de jogador e de goleiro, zoom pela roda do mouse e um botão de luz (Estúdio, Dia, Noite).
- Selo dourado **Oficial** quando o uniforme vem dos kits oficiais do jogo.
- Usa os kits 3D da sua pasta de gráficos e, se o clube não tiver, os oficiais do jogo. Kits instalados com o jogo aberto aparecem sozinhos.
- Opcional: com o plugin HeadHunter, o boneco ganha o rosto de um jogador do clube.
- Textos no idioma do jogo.

### Download

Baixe o `FMActionLink-Kits3D-1.0.0.zip` na página de [Releases](../../releases/latest).

### Instalar

1. Tenha o BepInEx 6 para IL2CPP (be.755 ou mais nova) no FM26.
2. Copie a pasta `FMActionLink.Kits`, que está dentro da pasta `plugins` do zip, para `BepInEx\plugins` do seu jogo.
3. Abra o jogo e a tela de qualquer clube.

Ajustes (luz, giro das camisas, camisas 2D ou 3D no cartão) ficam no arquivo `FMActionLink.Kits.look.cfg`. O passo a passo está no `LEIA-ME.txt` dentro do zip.

## English

Shows Football Manager 26 kits in 3D, inside the game itself.

- In the **About the Club** card, the 2D shirts become 3D shirts that gently sway.
- A button in the card's title opens the full player in 3D (shirt, shorts, socks and boots), with tabs for outfield and goalkeeper kits, mouse wheel zoom and a light button (Studio, Day, Night).
- A gold **Official** badge when the kit comes from the game's official kits.
- Uses the 3D kits in your graphics folder and, when the club has none, the game's official ones. Kits installed with the game open show up by themselves.
- Optional: with the HeadHunter plugin, the player gets the face of one of the club's players.
- Texts follow the game's language.

### Download

Get `FMActionLink-Kits3D-1.0.0.zip` from the [Releases](../../releases/latest) page.

### Install

1. Have BepInEx 6 for IL2CPP (be.755 or newer) in FM26.
2. Copy the `FMActionLink.Kits` folder, inside the zip's `plugins` folder, into your game's `BepInEx\plugins`.
3. Start the game and open any club's screen.

Settings (light, shirt spin, 2D or 3D shirts in the card) live in `FMActionLink.Kits.look.cfg`. The step by step is in `README.txt` inside the zip.
